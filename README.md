# Иви · ТВ-каналы — веб-прототип

Прототип раздела ТВ-каналов и телепрограммы онлайн-кинотеатра Иви: статический сайт на HTML/CSS/JS с подтягиванием реальных данных из публичного mobileapi Иви.

## Экраны
- `index.html` — каталог «ТВ онлайн» (ленты каналов, крупный спортивный блок, мегаблок «Топовые шоу»)
- `program.html` — программа передач (сетка каналов с расписанием, календарь дат)
- `player.html` — плеер канала с телепрограммой
- `schedule.html` — полная телепрограмма канала

## Варианты интерфейса
Шторка переключения режимов открывается свайпом/скроллом вверх у верхнего края:
- **As is** — как сейчас работает сервис
- **Вариант 1 / Вариант 2** — гипотезы нового опыта

## Локальный запуск
```bash
python3 server.py   # http://127.0.0.1:5180
```
(Обычный `python -m http.server` не используется из-за кириллицы в пути.)

## Данные
Публичный `api2.ivi.ru/mobileapi` без токена (CORS открыт). Часть данных (продолжение расписания, мета шоу) — демо.
